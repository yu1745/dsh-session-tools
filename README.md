# 会话工具

- **任务完成通知**：任务结束后发送浏览器通知，点击通知可打开对应会话。在「设置 → 通用」中开启。
- **独立对话目录**：选择「不在工作区工作」时，为每个新会话创建独立目录。指定项目的会话仍使用项目目录。
- **自动归档**：按最后活动时间归档闲置会话，时限可在「设置 → 通用」中调整。运行中和置顶会话会被跳过，归档后可恢复。
